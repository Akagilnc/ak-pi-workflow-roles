# Engine handbook basis on a resumed turn

This note applies to a labor turn that resumes an existing role session.

Read the engine handbook file named in **this turn's** materials
(`resources/engines/<name>.md`) from disk before assembling engine argv. A
read of that file from an earlier turn of the same session is not this turn's
basis: the packaged file may have changed since, and the body carried in the
session is only the older copy.

Material is data for the model, not a code contract. Do not invent package flags.
