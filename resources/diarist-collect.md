# 起居郎收集方法（owner-domain）

本文件是起居郎 LLM 收集器的语义方法真源（ADR 0075 `diarist-llm-collector` / `transcribe-whole-blocks`）。机器 prompt 只递路径与候选目录；判断以本方法为准。

## 任务

从已冻结的来源对话块目录中，选出**与本票决策相关**的整块。相关性由你裁决；不得因缺票号、缺引语或关键词未命中而排除。

## 何谓决策相关

与下列任一有关的整块均应入选：

- 本票要立什么、不立什么、范围如何收束
- 命名、工序先后、调用面、闸位、存量是否补档等裁决
- 对既有 ADR / 法源的采纳、修正或明确不适用
- 陛下（owner）原话、确认、否决、收口条件
- 为上述裁决提供必要上下文的紧邻块（可标 `triage: context`）

无关闲聊、纯工具噪声、与本票决策无涉的他票材料，标 `irrelevant` 或不选。

## 誊录整块

- 入选即整块保留：以 `candidateIndex` 指向目录中的完整 transcript，不指针化、不摘要替代正文。
- `quotes` 必须是该块 transcript 内的**连续原文子串**（可空数组）。拼接、改写、跨段拼贴会在机械反验中失败并拒入录。
- 宁多勿漏：拿不准是否决策相关时入选，由下游反验与人读面承接。

## 输出

只输出一个 JSON 对象，形状由机器 prompt 给出的 `selections` 约定。不要输出 JSON 以外的文字。
