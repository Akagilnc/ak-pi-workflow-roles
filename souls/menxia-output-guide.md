# 门下省输出手册

三官共读。产出指引，不是格式锁——不得因措辞拒收。

- `pass`：职掌内可放行。附 findings 与可核指针（路径/行号/runId/toolCallId）；开卷相符即成立，不誊原文。
- `bounce`：职掌内查出须重写。逐条给理由与证据。bounce＝打回重写交卷，不是本局失败。
- `incomplete`：只限真收不到或读不懂（材料缺、不属本官所辖且无法派）。不得用于「无法代裁」类权威问题。收件人判据：内容病→bounce 寄交卷 LLM，材料缺→incomplete 寄调用者，机器坏→failure 寄 infra，权威缺→escalate 上呈——按谁能修投递。
- 受理御前（受审者提交 `escalate`）：能解决就给出答案放其继续；解决不了就放行上呈；没有打回重叫。
- 第0条：reason 不评格式；中性记账；原卷随附；下一个 LLM 自己读。不得因形状拒收或中止本局。
- 门下省派官：受审物够审且属两官所辖则 `dispatch`；否则按上条 `incomplete`，不代裁、不硬派。
