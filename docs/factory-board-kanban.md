# 工厂进度板 · 衙门列道设计（owner grill 收敛真源）

> 2026-08-06 grill 会话收敛后成文。决策理由在 [ADR 0053](adr/0053-factory-board-kanban-yamen-columns.md)；本文为呈现层施工真源。锚定宪法：`data-*` 契约字节不动，呈现随时可重排。

## 板面结构

```
页头：工厂进度板 · 生成于 <本地时刻> · refresh ≤ Ns
      [项目下拉] [族下拉: 全部(默认)/open父票]        [未知票 ×N] ← 点击展开
      图例：圆点=状态 · 方色=衙门 · 面包屑=账本倒推真实轨迹（×N 折叠、↩ 回流）

列道（横向，左→右）：
  待发 → 大理寺(审票) → 将作监 → 刑部 → 门下省 → 已完成
```

## 列与归列判据（总判定表，优先级自上而下取一）

1. **retained closed**（留存窗内 merged，v1 = closedAt 代理）→ 已完成列；过期不上板；点名钻取关票常驻
2. **open 零卷** → 待发列（阻塞徽章叠加）
3. **当前站 = 最新 run**（#136「当前态只由最新 run 决定」）；latest = unknown → **未知集**（不做列、不因历史改列，右上徽章+展开）
4. **latest = judge** → 查全史是否存在已识别非 judge 站 run：无 → 大理寺（审票）列；有 → 刑部列（判卷）。unknown 历史不算开工证据
5. **latest = 其他 known 站**：coder → 将作监列；fixer / reviewer → 刑部列；collector → 门下省列；其余站 → 非常驻列（有票才现身，自动成列）。judge 永不生成非常驻 judge 列

- 未知徽章计数与展开列表消费同一个经项目/族筛选后的机械集合
- 已交卷待派**不做列**：卡停最后受理站，蓝点标识
- marshal 落地后其驱动 run 归刑部列（#140 US9 correlation 标 caller）

## 卡片

- **状态圆点+顶条**（卡不动窝只换色）：绿=在飞(<2min) / 黄=观察(2–15min) / 红=疑挂(>15min) / 蓝=已交卷待派 / 橙=escalate 待裁
- **衙门色签**：将作监 teal / 修内司 violet / 御史台 sky / 大理寺 rose（与状态色分离的色相）
- **面包屑轨迹**：账本倒推、连续同站折叠 ×N、↩ 标记回流（卡回左是正常环路）；被拒站划线
- **元信息**：成本 $ + tok（保留，不聚合）、腿龄/末次活动（中文时长格式）、等 #N 阻塞徽章、族徽章、model/provider/thinking
- **钻取**：卡内就地 `<details>` 展开 run 级明细（站点/结果判词/型号/成本/墙钟/ledger 链接，复用 S1 station 结构）

## 终态留存

- **merge+24h 消失**（v1：closedAt+24h），数据不动、契约全量
- **留存候选集供应**：默认板机械取得 closedAt+24h 窗口内关票与族计时所需已关父/子票——由既有 snapshot/watch 接缝供应并逐 tick 刷新（watch 不固定启动时快照）；closedAt 代理、显式册仓绑定不变，无 PR mergedAt，无新生产缝
- **族共享父票计时**：族根与成员由 GitHub 原生父子边机械形成；父票 closedAt 是全族唯一退场时钟——子票 merge 后常驻已完成列陪跑，父 closedAt+24h 全家（父+全部子票）一起退场；候选集须在父/子离开 OPEN query 后仍供其 closedAt 与父子边事实
- 已完成列内：单票平铺；**同族一簇**——父卡置顶、子卡缩进嵌套
- 点名钻取（--closed）的关票常驻

## 筛选与排序

- **项目下拉**：一册一选，默认 ak-pi-workflow-roles；初期不做「全部项目」
- **族下拉**：全部（默认）+ 有 open 子票的父票；选中时父票本体与子票同上板，列头计数随筛选集
- **列内排序**：在飞 → 观察 → 疑挂 → 已交卷，同档末次活动降序（最新动的浮顶）；**escalate 待裁 = 已交卷待派的裁决/颜色覆盖层（陛下裁）**，共享已交卷排序档
- 页头排序控件保留（票号/烧钱↓/烧钱↑）
