# 门下省开府：质量保证省与给事中、符宝郎、左拾遗

Status: accepted

门下省定为质量保证省，与干活的尚书省角色对举；本 ADR 只立角色与能力，不立编排。给事中对将作监/修内司产出行复杂度与测试质量两轴质检，符宝郎独立核验引语真伪与票面对齐，Collector 是门下省下的收证衙门，审刑院不入门下省编制、本轮零改动；形态为审刑院式一步制——session 内直接打回原流程，争议上抛陛下。后增设左拾遗：合并前以无锚定线上 bot 视角风闻奏事，只上弹章、无封驳权，不取代御史台狭义 bug 职掌；官职定义后经 ADR 0074 承继修正。

## Considered Options

封驳过大理寺两步制、复杂度/测试分设两官、扩审刑院收编乱引轴——均驳回。
