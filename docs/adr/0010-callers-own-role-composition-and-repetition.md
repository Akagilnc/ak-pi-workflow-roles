# 调用者拥有角色组合与重复

Status: accepted

角色只拥有单次调用的内政；调用者拥有角色之间的组合、顺序、重复次数、预算和停止条件。寺监级角色不得知道自己是第几次被调用、不得把工作流拓扑写入 Soul/schema/runtime/回执，仍应机械验证单次调用所需输入。省部级角色可在自己一次调用的内政之内作为 caller 派发正经角色，对其子调用拥有组合、预算与停止。Navigator 可在 typed 结算后建议下一包角色，建议无执行或授权效力；attendance 由共享生命周期信封供给。

## Consequences

roles package 对寺监级不含 orchestration 语义；同一角色可被不同调用者以不同拓扑复用；角色回执只证明该次调用，不表达下一步该调谁。
