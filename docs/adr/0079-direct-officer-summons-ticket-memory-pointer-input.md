# 交卷闸直接传召、衙门按票记忆、传召只递指针

Status: accepted

交卷闸按受审物直接传召具体衙门，不起门下省子 session；门下省仍可独立调用。映射：将作监/修内司完成侧→察院，大理寺判牒与给事中署章→符宝郎。察院/符宝郎/审刑院在同一父 run 内再传召 = resume 该席上一次 run，查找键为本次父 run 路径；给事中同票再传召同理 resume。自动同票 resume 保留，另增显式派新腿入口与显式 resume 并列，由调用者决定，机制不判断上下文是否超限。指针是绑定材料由代码精准递送；审核对话内容由父角色本轮 typed payload 原话传递，不由代码撰写。具名取代 ADR 0072 先调省再派官；修正 ADR 0075 显式票号旗结论。
