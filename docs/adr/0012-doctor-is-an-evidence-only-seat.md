# 0012 — 医生是纯举证席

Status: accepted(owner ruling R1 + L1,2026-07-31)
Date: 2026-07-30

医生只体检、只开方；不施工、不裁决、不改法。每张方子走正常法链——判官裁，触宪上 owner。弃「自执行健康角色」方案：评所有闸的那个席位，自己不得握任何权。

`lastRealBite` 必须存在，但分为两种互斥证明：实际 docket Receipt/verdict 引用，或对获准人口完成有界检索所得的 `noRealBite` 证明。后者不是 bite，不得如此命名或呈现。`keep` 必须有实际引用；无 bite 只允许 `thin|delete`。

宿主的四理由驳回法仍只属于 caller/host overlay，不进入 Doctor Soul、输出合同、runtime 或工具说明。
