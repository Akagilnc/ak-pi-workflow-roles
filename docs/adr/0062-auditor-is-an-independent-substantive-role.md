# 审刑院是独立的实质审计角色

Status: accepted（陛下 2026-08-09 拍定）

审刑院作为单独角色自行取证，既判断「该有的有没有」，也判断「有的对不对」，不再限于只看既给材料或只审程序；法源原话：「不起一局了。我改主意了。单独角色」「全改。不并存了。」及「审刑院soul里两大职责。1 判断该有的有没有，2 判断有的对不对！谁说审刑院只是秘书看格式对不对的！」。本决定具名取代 [ADR 0006](0006-soul-audit-same-model-fresh-call.md) 的上下文隔离与任务窄化条款。

**射程修订（2026-08-10，[ADR 0066](0066-worker-typed-submission-gates.md)）：** 修内司道 LLM 审刑院代码腿按 #242 退役（soul 文件保留备用）；本 ADR 继续约束仍接线的审刑院席（判官道等）。修内司/将作监的 typed 交卷闸与 git 前置闸见 0066，不在本条扩权。
