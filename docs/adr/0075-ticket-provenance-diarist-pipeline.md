# 每票起居录与起居郎

Status: accepted

每票一份起居录送司天台，kind 为 ticket-provenance，修正 ADR 0065 二期 scope；真源是司天台 JSONL，人读面只是渲染；历史按票键组织，存量票不补档，人读面只落本地加票面指针。起居郎是 LLM 角色（soul、席位、公开入口、交卷工具），负责把本 issue 决策相关整块对话抓来入录，不可变记录间不适用 DRY，对话源不限于单一宿主；起居郎 LLM 自行认票，相关性只由 LLM 裁决，机械层不做引文/票号/相关性判定，不加全局 --ticket 旗；起居郎交什么记什么，投影失败只记未投影不丢原文。不规定谁调用起居郎、不把顺序写进法，每次过庭都跑是调用者用法、增量幂等；符宝郎挂给事中交卷闸——认得出票→有录并读录核旨，真无票→无录；合审时可另交 courtTicketNumbers 集合并逐票 refresh，主票绑定不变。
