# 每票起居录与起居郎

Status: accepted

每票一份起居录送司天台，kind 为 ticket-provenance，修正 ADR 0065 二期 scope；真源是唯一 `records.jsonl`（#900 起人读面取消），历史按票键组织，存量票不补档。起居录以陛下与 runner 的完整对话为主体，两边都记；可解析且可按结构化来源分类的独立工具事件、机器块、ADR 原件与票面不另采为条目，说话人正文原样保留。起居郎是 LLM 角色（soul、席位、公开入口、交卷工具）：自行认票并划出对话边界，正文由机械按边界从宿主会话卷投影；无法解析的源行不补写、不伪造对话字段，以原字节留卷。边界不可用走既有 reask，不中止本轮。对话源不限于单一宿主；相关性（哪段属本票）只由 LLM 裁决，机械层不做引文/票号/正文过滤，不加全局 --ticket 旗。不规定谁调用、不把顺序写进法，每次过庭都跑是调用者用法。符宝郎挂给事中交卷闸——认得出票→有录并读录核旨，真无票→无录；合审时可另交 courtTicketNumbers 集合并逐票 refresh，主票绑定不变。实现形状与失败处置见 #901。

**范围修订（#901 / 2026-09-14，与 ADR 0081 同步）：** 陛下实答「D 不支持旧卷」。精确射程＝**旧版 Codex 卷中缺行级 provenance（如 `content_item_kinds` 含 `user.*`）的 owner 输入**不入录、不在 cross-host 支持范围；不得以正文或全卷 originator 冒充行级事实。例外不扩及其他已有可靠结构化说话人事实的宿主。「无原生 id」仍可按 #901 兜底；「无行级 provenance」的旧 Codex 不在兜底之列。不为旧卷另建识别机制、不加正文判断。

**累计与结转（#918 / 2026-09-15，给事中复庭通过）：** 取代「本轮 ranges 即当前完整快照、遗漏即撤回」与「每轮整卷重读历史源重投影」。册子头 `sessions` 为 prior ∪ 本轮的累计并集（ranges 累计单调、遗漏不删除、不设撤回）；同卷新增范围与新 session 索引均保留。**已投影内容即卷宗**：原字节结转，不以历史源可读为发布前置；本轮只对 prior 未声明的 range（或既有 session 的新增区间）读源。精确重复提交＝幂等 no-op。物化 user 按自身 typed `origin.kind` 判来源；enqueue 与物化 user 没有 typed 关联，不以位置或正文 identity 反扣，只保留已获御裁的 `<task-notification` 固定起始形状判据，其余维持现状。

**修订（#926）：** 对话条目不再携带不稳定的物理 `line`，保留 `s` 与原生 `id`，并由 runtime 在交卷 payload 旁记录 `sourcePosition` 稳定位置事实。位置按源卷的逻辑事件序列生成：有原生 id 的重放拷贝归同一位置；无 id 的行按前一原生 id 后的序号归位，不读取正文，也不把物理行号换名复活。累计折叠按 `(s, sourcePosition)` 排序，故同卷先录后段再补前段仍保持源序；升级前缺该事实的有 id 条目在读取时从仍可读源卷恢复位置，源不可读时才维持既有相对次序。已发布条目的事后改写与首次成录坏行补写两层 amendment 均删除；无法解析的 range 内源行作为未投影原字节留卷，不冒充 owner／runner 条目。因而 dialogue-only 的排除规则只判断可解析、可按结构化来源分类的事件。
