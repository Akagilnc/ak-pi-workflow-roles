# 每票起居录与起居郎

Status: accepted

每票一份起居录送司天台，kind 为 ticket-provenance，修正 ADR 0065 二期 scope；真源是唯一 `records.jsonl`（#900 起人读面取消），历史按票键组织，存量票不补档。起居录**仅限对话**：只收陛下与 runner 的完整对话，两边都记；排除按来源不按正文——独立工具事件、机器块、ADR 原件与票面不另采为条目，说话人正文原样保留。起居郎是 LLM 角色（soul、席位、公开入口、交卷工具）：自行认票并划出对话边界，正文与定位由机械按边界从宿主会话卷投影；可解析行机械写入，解析不了的行跳过并交其补写；边界不可用走既有 reask，不中止本轮。对话源不限于单一宿主；相关性（哪段属本票）只由 LLM 裁决，机械层不做引文/票号/正文过滤，不加全局 --ticket 旗；起居郎交什么记什么，投影失败只记未投影不丢原文。不规定谁调用、不把顺序写进法，每次过庭都跑是调用者用法；每轮按当前区间重投影唯一册。符宝郎挂给事中交卷闸——认得出票→有录并读录核旨，真无票→无录；合审时可另交 courtTicketNumbers 集合并逐票 refresh，主票绑定不变。实现形状与失败处置见 #901。

**范围修订（#901 / 2026-09-14，与 ADR 0081 同步）：** 陛下实答「D 不支持旧卷」。精确射程＝**旧版 Codex 卷中缺行级 provenance（如 `content_item_kinds` 含 `user.*`）的 owner 输入**不入录、不在 cross-host 支持范围；不得以正文或全卷 originator 冒充行级事实。例外不扩及其他已有可靠结构化说话人事实的宿主。「无原生 id」仍可按 #901 兜底；「无行级 provenance」的旧 Codex 不在兜底之列。不为旧卷另建识别机制、不加正文判断。
