# Worker typed 交卷闸与 git 前置闸；修内司 LLM 审刑院退役

Status: accepted

退役 Fixer LLM 审刑院代码腿（soul 文件原地保留备用），以 typed 交卷闸替代其打回权能；闸权是 bounce 重写，不是拒收、不是角色失败、不是终止进程。闸①：completed/partially_completed 且零新 commit 时打回一次未观察到 commit 的提醒，同 run 重交视为确认，planned/refused/unfinished 零 commit 合法；闸②平台前缀域为开放集（工厂 worker 冠 ak-roles:，直改通道前缀保留，merge commit 豁免），后由 ADR 0070 改在交卷接缝软提醒；闸③⑤不建，闸⑥允许 fixer 交 testEvidence 字段但机器不查。跨 resume 的 baseline 与打回记录须经 ADR 0065 司天唯一入口写入；不 supersede ADR 0024/0055/0057，修订 ADR 0006/0062 射程使修内司道不再是在役适用对象。
