# 机器文本中立法

Status: accepted

机器组装、进入角色 LLM 视野的一切文本须全中文、不复述 soul 已有内容，且不得替衙门限定工作范围、预设结论或引导判断（如指定只查上一轮的几条）。`/skill:` 裸绑定串豁免已由 #1043 替代，不得再作为往任务文字注入 Skill 前缀的理由；引擎行为义务真源住 resources 与 soul，由 typed 失败机制执行。代码自写指令句删除后，确需对角色说的话归入包资源文档随案附卷；指针句属中立绑定材料可保留。

本意：陛下 2026-09-17「这个本意是之前给的prompt指令太强，影响衙门正常工作。比如指定工作范围，指定只查上一轮的几条这种。但是现在的措辞又有点过于绝对了」（源卷 `e4b50c8e-15c7-4c92-9263-959efadb24eb`，uuid `68e51d84-80b1-42ec-a293-8bcbf79c6d41`）。
