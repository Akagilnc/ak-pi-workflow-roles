# 0073 — 机器文本中立法：全中文、不复述 soul、零指令零方向

Status: accepted（owner 2026-08-27 三令 + 两项边界裁定，本 ADR 即冻结件）

## 御笔原话（2026-08-27，逐字）

> 用中文显示 开场令。
> 所有的开场，加载，附属话术，输出工具描述
>
> soul里面有的东西，不许额外再次说明。 所有的文字只是为了 启动回话，说明输出等中立描述。不应该有任何指令和命令，方向判断的东西

## 决策

机器组装、进入角色 LLM 视野的一切文本——开场令、加载/递材料话术、附属话术（催交、打回、接受、拦截等）、输出工具的 description 与字段说明——受以下三条约束：

1. **全中文。**
2. **不复述 soul**：soul（及法典/手册等 owner 域材料）已有的内容，机器文本不得再次说明；soul 是唯一真源。
3. **只许中立描述**：机器文本仅承担启动会话、递交材料、说明输出形状等中立功能；不得含任何指令、命令或方向判断。

## 边界裁定（owner 2026-08-27）

- **`/skill:` 绑定串豁免**：`/skill:<名> <原始输入>` 是加载随包方法的机制机关（ADR 0032/0052），不算「命令」，不受本法约束。边界：仅豁免裸绑定串，不得夹带散文。
- **引擎行为法承接**：ADR 0071 的「必须真调用、失败即停、禁顶班」等行为义务，真源住 `resources/engine-dispatch.md`、各引擎笔记与 soul 层（owner 域方法文档，不属机器文本）；其强制由 typed 失败机制执行（#483 已落地）。机器工具文本只留中立形状说明。

## 影响面

全仓机器文本整改按本法执行；整改案与逐条核对由庭审卷宗承接（run 01a040ce-1eb6-76a1-bbd1-2705c55afb14 escalate 后续）。souls、法典、手册、engine 笔记等 owner 域文档不属本法对象。
