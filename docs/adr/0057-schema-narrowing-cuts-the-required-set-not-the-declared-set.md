# 交卷 schema 仅三态判别必填

Status: accepted

正常审核判词的 schema 除三态判别字段（枚举并必填，作宿主生成端约束）外 required 为空；其余字段保留声明与 description、不必填，顶层允许额外属性。同一终局工具上，真实基础设施失败声明是三态必填的唯一获准例外，可不带审核 status；这不是审核结论，也不把失败伪作三态。声明不是包侧校验授权：包不因格式拒收或判死；判别字段没填或读不出时只说读不出并附收到的值，不在代码里写状态名。key 名字不必逐字相同，合不合格由审刑院按是否读得懂来判。（#1055。三态必填：源卷 d634a8d9。无 status 失败例外：源卷 e4b50c8e-15c7-4c92-9263-959efadb24eb.jsonl，owner uuid 06da83bf-325e-4755-9373-9a4141de0f12、2ebd8a3c-2482-4a28-a429-1ea0592283ec）
