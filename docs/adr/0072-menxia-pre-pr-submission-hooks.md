# 开 PR 前门下省交卷挂钩

Status: accepted

开 PR 前的交卷挂钩调具体质检席（后由 ADR 0079 改为直接传召，不再先起门下省子 session）：将作监/修内司 completed/partially_completed → 给事中（后改察院）；planned/refused/unfinished 不调；大理寺拟判入卷后 → 符宝郎；审刑院只挂大理寺、零改动。封驳＝当场打回重写交卷，本局未失败。开 PR 之后整段后做。

## Considered Options

交卷钩直接起给事中/符宝郎（当时驳回，后由 0079 取代）、给事中挂大理寺判卷、非完成侧仍调——均不采或后改。
