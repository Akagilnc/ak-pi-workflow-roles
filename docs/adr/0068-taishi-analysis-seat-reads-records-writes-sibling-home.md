# 太史：司天台分析席

Status: accepted

太史是司天台的分析席：确定性机制、只读司天台记录、可作为角色单独调用；高阶数据落基础记录同家下的独立目录，不进业务仓。建设排在司天二期记录工程之后；自动 per-merge 触发挂起，现形态为 caller-invoked 巡扫 CLI，pull-anytime 仍在。公开查询范围是簿（cwd git common-dir）× 可选票过滤；删除 --project-root，model-groups 多 root 入口诚实停用。初期效率代理为改动行数加总耗时，首批关注时桶与角色成功率。

## Considered Options

一次性探针不设席、每 issue 归属做成记录内机械字段、发明单一效率分——均不采。
