# 包只做路由与透传：派单文原样、文件旗只传路径、代码不向衙门递路径

Status: accepted

包在调用方与衙门之间只做路由和透传。此前包在中间加了一层加工：把 `--attach` 的文件复制进腿目录、把抄件路径接在派单文后面；把派单文再抄成腿目录里的文件、从启动材料递它的路径或重复它的全文；校验并改写 `--prerequisites`；向被传召的审核席递被审腿的目录路径，三席三种给法。腿目录在衙门自报票号后由 unbound 挪进票号目录，这些路径随之失效；出故障的是这层加工，不是衙门。

决定：

- **派单文**原样成为衙门的首句，前后不加字；包不把它另存成文件再递路径，也不在启动材料里重复。
- **文件旗**（`--attach`、`--prerequisites`、`--request-manifest`）只把调用方给的路径照原样告诉衙门，不换算成别的路径。包不读、不复制、不校验、不改写，不记字节数与校验值；卷宗只在受理的输入里记下这个路径。用法写在 README 与 help；传错了由衙门处置。
- **代码不向衙门递任何路径。** 衙门凭规矩自己找：记录在票号目录下，没有票号在 unbound 下。
- **被审腿的身份**统一是 `<runId>@<席>`，各审核席同一给法，不带路径。
- **外包及其手册**属启动材料，不进派单文。
- 审核对话原话传递不变，见 [ADR 0085](0085-ledger-before-audit.md)。

曾考虑保留受理时的附件抄件，留一份原样供事后核对；它换来的是复制、记账、归位时改路径、同票再传召时再抄、重放时携带这一整串，抄件路径仍随归位失效，弃。曾考虑不给被审腿身份、由审核席按票号自找；一张票下同席常有多条腿，自找既费又可能认错，而包手里有准确身份，且身份不是路径、不随归位变，故给身份。
