# 派单原样透传，文件旗只传路径

Status: accepted

包对派单只做路由与透传：派单文原样成为衙门的首句，包不另存成文件、不在启动材料里重复、不在其后接字；文件旗（`--attach`、`--prerequisites` 等）只把调用方给的路径原样告诉衙门，包不读、不复制、不校验、不改写，卷宗只在受理的输入里记下这个路径；外包手册属启动材料，不进派单文。理由：文件在不在、格式对不对，衙门读得出也处置得了，代码抢先去做只多出一层会坏的加工——受理时的抄件路径在腿归位后即失效。与 [CLAUDE.md「起居录位置」](../../CLAUDE.md#起居录位置1092)、[ADR 0086](0086-host-dossier-is-native-file-copy-sitian-append-only.md) 同一道理，代码也不向审核席递被审腿的路径：只给身份 `<runId>@<席>`，各审核席同一给法，修订 [ADR 0079](0079-direct-officer-summons-ticket-memory-pointer-input.md)；审核对话原话传递仍依 [ADR 0085](0085-ledger-before-audit.md)。曾考虑保留受理时的附件抄件供事后核对，它带出复制、记账、归位改路径、再传召再抄、重放携带一整串，弃；曾考虑不给被审腿身份、由审核席按票号自找，一票多腿时既费又可能认错，弃。
