# 大理寺、审刑院与御史台不受 runtime 工具限制

Status: accepted（陛下 2026-08-09 拍定；2026-08-10 扩射程至御史台；2026-08-23 扩射程至门下省、给事中、符宝郎）

大理寺与审刑院可读、可写、可查并可临时造夹具或改代码测试，只须最终恢复原样，runtime 不得任意缩窄其取证工具；法源原话：「大理寺和审刑院没有工具限制。可读，可写，可查，可以自己造夹具，可以改代码测试，只要最终恢复原样。而且别给我上什么强校验。」

2026-08-10 扩射程：御史台同权，任何机制不得以白名单或授权面缩窄其取证手段；法源原话：「御史台就不该被派单束缚。就该是独立审核」。

2026-08-23 扩射程：门下省、给事中、符宝郎同权。给事中、符宝郎与大理寺、御史台一样没有工具限制；通进司仍是收证，不因同省取得施工取证权。挂钩见 [ADR 0072](0072-menxia-pre-pr-submission-hooks.md)。

2026-08-27 扩射程：左拾遗（gleaner-left）同权，探针用毕清理并如实记载。席位法源原话见 [ADR 0067](0067-menxia-province-founding-jishizhong-fubaolang.md) 修正案；本条扩权批语：「f1f2可以补」。
