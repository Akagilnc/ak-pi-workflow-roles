# 引擎绕行失败交回席位；外包只作尽量要求

Status: accepted

引擎绕行失败（真被调用后 spawn 失败、非零退出、空输出等）把真实原因与已有进程结果交回发起调用的同一角色 session，保留既有记录；包不得因这次外包失败主动终止该席位 run 或替它定失败终局（#1213 纠正）。同一接缝收到空或不能执行的命令参数时，把参数错误交回该席位，不升格为整腿失败或主动中止（#1213 A3）。后续如何处置由该席位判断，交卷与终局仍走既有通道；成功返回劳动结果的行为不变。外包要求为尽量外包，别自己干；不得静默换用其他引擎 id；原 engineLaborFallback 申报废止。席位挂了 engine 而零次调用，不构成交卷不合法，任何衙门不得据本条撤销、作废、重跑该 run 或拒绝结算其产出。runner 义务只到派单要求外包；未配型号的席位按既有引擎材料办，runner 不得发明型号。
