# 0048 — 候簿拓扑：一家多簿，session 直落家，键=主仓目录名，git-only

Status: accepted（owner 拍定，2026-08-03）

候簿集中在包所有的机器级一家（可枚举、消费者仓零侵入），session 直接写进家、不设归档搬运；分簿键=git common dir 宿主目录的 basename（worktree 归宗主仓名），git 是包的基质要求——非 git 目录点火即响亮拒绝。目录改名分簿、无关项目撞名并簿均按 no-100%-defense 接受为账面可见的 cosmetic 事件。（键不看历史不取输入：改史、改 remote、乱输在构造上都碰不到它。）
