# 0074 — 门下省改组：给事中票庭审读、察院分立、大理寺收缩至判卷

Status: accepted（owner 2026-08-30 两轮 grill 收口，decision keys 与绑定原话见下；实施见 #572）

## 背景

票庭（开工前的票面听证）由大理寺主持，名实倒挂：大理寺的判卷本能使其把实现细节过早泼上票面，而其实际被调用最多的形态是事后审核。五问——①决定是否符合既定制度②授权是否真实③文书是否与原意一致④是否存在必须退回重议的问题⑤是否具备正式发布与执行资格——在三场票庭（#552/#553/#556）中已是事实宪法，却无编制承 ownership。授权出处被 LLM 乱编乱扩「已经发生过无数次」（#553 对账表伪真源、#556 关票无陛下原话），无席首责。现行「给事中」行事后复杂度/测试质量质检，是御史台察院的职，名实不符。

## 决策

### 编制

门下省改组为审署诏敕的省：

| 席位 | 机器键 | 职 |
| --- | --- | --- |
| 给事中 | `countersign`（新） | 票庭审读五问；开工前由调用者传召，非闸派 |
| 符宝郎 | `notary` | 首责唯一=实际授权出处核真；引语真伪/票面对齐为手段 |
| 察院 | `inspector`（不动） | 事后察举：复杂度/测试质量；独立出门下省编制，交卷闸派发不断；挂靠御史台挂起 |
| 通进司 | `collector` | 收证（不变） |

大理寺（`judge`）退出票庭，收缩为事后判卷定谳；其查证/质检主责移察院。

### trade-off 三条

1. **merit＝给事中传召权，非独立庭**：五问之外，实质听证（设计是否成立、证据是否为真）由给事中传召取证行使；裁决落法度与事实，不落施工设计。
2. **署＝意见，非 merge 硬闸**：给事中的署放行的是开工资格；merge 按钮仍归调用者，[ADR 0010](0010-callers-own-role-composition-and-repetition.md) 主权不动。
3. **大理寺保留判，不保留审**：事后判卷定谳是独立职能且为收敛环承重件；事前审读整体移交。

### 交卷闸

触发条件、派发逻辑、schema 零改动；受审物→官映射中「给事中」更名「察院」，符宝郎不变。
