# 删留之争采承接者判据

Status: accepted

删与留之争以**承接者判据**为可核验标准：删掉之后，那一类失败还有没有人接？有人接，删就是正事；没人接，保留才是容错。「容错」本身不可核验，承接者可以——去代码里看该失败类别的处理路径是否与既有机制相交。本判据不倒置 ADR 0036 的举证责任：举证仍在保留方，只是把「特别理由」钉成「指出无替代承接者」。**无承接者是保留的必要条件，不是充分条件**：仍须过护栏三问（`souls/quality-law.md`），且不得落入 ADR 0036 的失格类别。ADR 0036 仍是一票大扫除的删除默认姿态，本 ADR 不扩张其射程。曾考虑把判据留在词表、扩写 ADR 0036，或只靠 quality-law 三问；词表不是规则真源，0036 是一票姿态不宜扩成通用判据，三问不单独钉住「有无承接者」，故单立本 ADR（#970；owner `b6b8b383-0579-453b-95eb-1a4ad6e18d80`）。
