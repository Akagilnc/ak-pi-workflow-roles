# 起居郎成录，起居录直接随案递送

Status: accepted

本页最初决定由公共入口将起居录随案递送，目的在 #900 后收窄为免去到 session 大海里找本票对话，ADR 与设计的发现交还各衙门本职；递送本身不触发起居郎刷新，系统随案引用与调用者附件是两类材料、不相互覆写。票已绑定但案卷缺失或不可读时如实交代，按既有故障与裁量路径处理，不新增格式拒收或自动停工机制。记录已有结果而现有提要求逻辑不变；设计修订由起居郎补录并重新过庭。后续角色沿用起居录票号并删除独立 LLM 认票工序，首次审票由调用者给票号；自动化只检查正常生成，内容交大理寺和实际使用判断。

以上为原决定背景：递送已由 #1092 撤销，票庭刷新及认票已由 2026-09-29 修订取代。划段方法见 [起居郎材料](../../resources/diarist-collect.md)；成录机制及其 #918/#926 历史、#901 范围、#1090 纯追加决定由 [ADR 0075](0075-ticket-provenance-diarist-pipeline.md) 单一承接。ADR 0078 承接列表义务已由后出 ADR 0083 承继作废，本页不再遵守键表体例。

**修订（#1090 / 2026-09-27）：** 当时撤销成录侧重放折叠与位置刷新，未改本页递送路径；决定全文及授权原话、源卷 uuid 见 [ADR 0075 的 #1090 修订](0075-ticket-provenance-diarist-pipeline.md)。

**范围修订（#901 / 2026-09-14）：** 本页原载的例外与无原生 id／无行级 provenance 区分已合入 [ADR 0075 的 #901 决定](0075-ticket-provenance-diarist-pipeline.md)，不再与其平行维护。

**范围修订（#1071 / 2026-09-25）：** 无父 run 的独立中段公开调用（御史台／大理寺／修内司等），开跑前包没有票号，不得要求包预先递送起居录，也不新增中段 `--ticket` 旗。角色读取约定见 [CLAUDE.md「起居录位置」](../../CLAUDE.md#起居录位置1092)；票号字段见 [交卷声明](../../src/package-contracts/terminating-infrastructure.ts)，归位判据见 [卷宗拓扑](../dossier-topology.md) 与 [run 生命周期接缝](../../src/public-cli/run-lifecycle.ts)。已绑定父子传召与同席续跑仍沿用既有身份。

**范围修订（#1092 / 2026-09-27）：** 撤掉本页「公共调用入口将起居录直接随案递送」与代码计算／冻结／注入起居录路径指针的旧决定。现行自取、路径及递送边界见仓内 [CLAUDE.md「起居录位置」](../../CLAUDE.md#起居录位置1092)，本页不再复述该约定。#1071 自取与申报归位、其他阅读材料与 typed payload 原话传递不变。

**修订（2026-09-29）：** 给事中开庭不再自动起起居郎：开庭认票与按票刷新两处都撤，上文「保留票庭刷新」半句作废，何时跑起居郎回到调用者。本票自上次成录后陛下有新话，调用者在开庭前跑一次；多票庭只跑一个，指令列全部票号，由起居郎按票分录。给事中的票号以起居录为先：本票已有起居录的直接用其票号，没有的由给事中自己判断；两种情形都在交卷 `ticketNumber` 申报。中书省立票前的起居郎不变。调用者漏跑不另设提醒或检查，缺录由符宝郎按既有职责发现并上呈。
