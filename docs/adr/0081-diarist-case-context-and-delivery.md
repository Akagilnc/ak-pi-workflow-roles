# 起居郎成录，起居录直接随案递送

Status: accepted

起居郎为本票划出对话段、由机械成录，公共调用入口将起居录直接随案递送，何时跑起居郎归调用者；#900 后案卷目的收窄为免去到 session 大海里找本票对话，ADR 与设计的发现交还各衙门本职。划段：在实际参与本案的宿主会话里找本票对话并交边界（不限 Claude；跨宿主无原生 id 时按 #901 形状兜底），不搜集票面与 ADR 原件。成录：可解析行由机械按边界投影；解析不了的 range 内源行以未投影原字节留卷，不补写、不伪造说话人与正文。对话条目保留 `s` 与原生 `id`，不携带物理 `line`；runtime 另记不读取正文的重放稳定 `sourceIdentity` 与本轮投影时的 `sourcePosition` 源序快照。已发布条目也不存在 amendment 改写通道。递送：已有本票身份与指针输入，不把正文塞进提示词；递送本身不触发起居郎刷新；系统随案引用与调用者附件是两类材料、不相互覆写；票已绑定但案卷缺失或不可读时如实交代，按既有故障与裁量路径处理，不新增格式拒收或自动停工机制。记录已有结果而现有提要求逻辑不变；保留票庭刷新，设计修订由起居郎补录并重新过庭。后续角色沿用起居录票号并删除独立 LLM 认票工序，首次审票由调用者给票号；自动化只检查正常生成，内容交大理寺和实际使用判断。ADR 0078 承接列表义务已由后出 ADR 0083 承继作废，本页不再遵守键表体例。

**修订（#1090 / 2026-09-27）：** 与 ADR 0075 同步。废止成录侧「重放身份归并后按源序折叠」与跨次位置刷新：本轮交来的边界整段投影并追加；同一区间再次提交新增一条记录，不回读已成录历史去重。随案递送路径指针仍保留；递送本身仍不触发起居郎刷新。授权指针见 ADR 0075 #1090 修订。

**范围修订（#901 / 2026-09-14）：** 陛下实答「D 不支持旧卷」。精确射程＝**旧版 Codex 卷中缺行级 provenance（如 `content_item_kinds` 含 `user.*`）的 owner 输入**不在 cross-host 支持范围、不入录；不得以正文、措辞、模板或全卷 originator 冒充行级事实。本例外**不**扩及 Pi 或其他已有可靠结构化说话人事实的宿主，也**不**要求一切跨宿主来源均须具备 `content_item_kinds`。「无原生 id」与「无行级 provenance」是两件事：有行级 provenance 但无原生 id 的来源仍按 #901 形状兜底；无行级 provenance 的旧 Codex 不在兜底之列。不为旧卷另建识别机制、不加正文判断。

**范围修订（#1071 / 2026-09-25）：** 无父 run 的独立中段公开调用（御史台／大理寺／修内司等），开跑前包没有票号，不得要求包预先递送起居录，也不新增中段 `--ticket` 旗。办票角色按自己知道的票号自取本票起居录；在既有结构化交卷的 `ticketNumber` 字段申报本票号，归位接缝按该申报归入对应票账本（原话照录；字段形状可辨则归位，不可辨则留 unbound；不从回执散文或派单文猜票）。已绑定父子传召与同席续跑仍沿用既有身份。

**范围修订（#1092 / 2026-09-27）：** 撤掉本页「公共调用入口将起居录直接随案递送」与代码计算／冻结／注入起居录路径指针的旧决定。公开入口与内部传召不再为起居录算路径、冻附件或装阅读材料；角色按票号自取。本票记录目录的固定约定写入仓内公共文件（`CLAUDE.md`），不写 Soul；该约定可随既有参考材料进入每轮／resume 的提示，代码不逐次计算、冻结或递送本票指针。#1071 自取与申报归位、其他阅读材料与 typed payload 原话传递不变。

**修订（2026-09-29）：** 给事中开庭不再自动起起居郎：开庭认票与按票刷新两处都撤，上文「保留票庭刷新」半句作废，何时跑起居郎回到调用者。本票自上次成录后陛下有新话，调用者在开庭前跑一次；多票庭只跑一个，指令列全部票号，由起居郎按票分录。给事中的票号以起居录为先：本票已有起居录的直接用其票号，没有的由给事中自己判断；两种情形都在交卷 `ticketNumber` 申报。中书省立票前的起居郎不变。调用者漏跑不另设提醒或检查，缺录由符宝郎按既有职责发现并上呈。
