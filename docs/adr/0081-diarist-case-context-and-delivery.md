# 起居郎整理本案依据，起居录直接随案递送

Status: accepted

起居郎为本票找齐、整理相关依据（用户决定、设计、适用 ADR 与裁决），公共调用入口将起居录直接随案递送，何时跑起居郎归调用者；案卷替各衙门集中本案依据，记录已有结果而现有提要求逻辑不变，Soul 只说明材料用途、不负责派送；保留票庭刷新，设计修订由起居郎补录并重新过庭；已有材料多数通过指针引用，主动搜集不限于单一宿主会话，相关性由起居郎判断。递送使用已有本票身份与指针输入，不把全部原始卷宗塞进提示词；递送本身不触发起居郎刷新；系统随案引用与调用者附件是两类材料、不相互覆写；票已绑定但案卷缺失或不可读时如实交代，按既有故障与裁量路径处理，不新增格式拒收或自动停工机制。后续角色沿用起居录票号并删除独立 LLM 认票工序，首次审票由调用者给票号；自动化只检查正常生成，内容交大理寺和实际使用判断；ADR 0078 承接列表义务已由后出 ADR 0083 承继作废，本页不再遵守键表体例。
