# 起居郎成录，起居录直接随案递送

Status: accepted

起居郎为本票划出对话段、由机械成录，公共调用入口将起居录直接随案递送，何时跑起居郎归调用者；#900 后案卷目的收窄为免去到 session 大海里找本票对话，ADR 与设计的发现交还各衙门本职。划段：在实际参与本案的宿主会话里找本票对话并交边界（不限 Claude；跨宿主无原生 id 时按 #901 形状兜底），不搜集票面与 ADR 原件。成录：可解析行由机械按边界投影；解析不了的 range 内源行以未投影原字节留卷，不补写、不伪造说话人与正文。对话条目保留 `s` 与原生 `id`，不携带物理 `line`；runtime 另记不读取正文的重放稳定 `sourceIdentity` 与可刷新的 `sourcePosition` 源序快照，使重放拷贝归同一逻辑身份，并使源卷前插或同卷后补区间后仍按本次可见源序折叠；混合升级存量中无法恢复位置者排在有位置条目后并维持原卷序；已发布条目也不存在 amendment 改写通道。递送：已有本票身份与指针输入，不把正文塞进提示词；递送本身不触发起居郎刷新；系统随案引用与调用者附件是两类材料、不相互覆写；票已绑定但案卷缺失或不可读时如实交代，按既有故障与裁量路径处理，不新增格式拒收或自动停工机制。记录已有结果而现有提要求逻辑不变；保留票庭刷新，设计修订由起居郎补录并重新过庭。后续角色沿用起居录票号并删除独立 LLM 认票工序，首次审票由调用者给票号；自动化只检查正常生成，内容交大理寺和实际使用判断。ADR 0078 承接列表义务已由后出 ADR 0083 承继作废，本页不再遵守键表体例。

**范围修订（#901 / 2026-09-14）：** 陛下实答「D 不支持旧卷」。精确射程＝**旧版 Codex 卷中缺行级 provenance（如 `content_item_kinds` 含 `user.*`）的 owner 输入**不在 cross-host 支持范围、不入录；不得以正文、措辞、模板或全卷 originator 冒充行级事实。本例外**不**扩及 Pi 或其他已有可靠结构化说话人事实的宿主，也**不**要求一切跨宿主来源均须具备 `content_item_kinds`。「无原生 id」与「无行级 provenance」是两件事：有行级 provenance 但无原生 id 的来源仍按 #901 形状兜底；无行级 provenance 的旧 Codex 不在兜底之列。不为旧卷另建识别机制、不加正文判断。
