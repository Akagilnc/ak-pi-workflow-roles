# 起居郎成录，起居录直接随案递送

Status: accepted

起居郎为本票划出对话段、由机械成录，公共调用入口将起居录直接随案递送，何时跑起居郎归调用者；#900 后案卷目的收窄为免去到 session 大海里找本票对话，ADR 与设计的发现交还各衙门本职。划段：在实际参与本案的宿主会话里找本票对话并交边界（不限 Claude；跨宿主无原生 id 时按 #901 形状兜底），不搜集票面与 ADR 原件。成录：可解析行由机械按边界投影，解析不了的行跳过并交起居郎补写；不产自撰解释，人读面取消。递送：已有本票身份与指针输入，不把正文塞进提示词；递送本身不触发起居郎刷新；系统随案引用与调用者附件是两类材料、不相互覆写；票已绑定但案卷缺失或不可读时如实交代，按既有故障与裁量路径处理，不新增格式拒收或自动停工机制。记录已有结果而现有提要求逻辑不变；保留票庭刷新，设计修订由起居郎补录并重新过庭。后续角色沿用起居录票号并删除独立 LLM 认票工序，首次审票由调用者给票号；自动化只检查正常生成，内容交大理寺和实际使用判断。ADR 0078 承接列表义务已由后出 ADR 0083 承继作废，本页不再遵守键表体例。
