# 角色按唐宋官署命名

Status: accepted

角色以唐宋官署/官职命名，判据是结构同构而非职掌精确对上，不硬凑，好听是硬尺子，监察席上奏不执法，不为整齐或成对而造席位；朝廷对应皇帝＝陛下、宰相＝调用者/主 session、百官＝各角色，已定名单见 README 班子总表。中文名是呈现，机器可消费的键默认不变；太史/司天台 live 机器面已按 analyst/archivist 全量改名不留兼容别名，marshal 中文名定名尚书省而 canonical 键不变，医生中文名定名太医署而 CLI 标识符 doctor 不变。三法司是职责分立类比不是流程链，本 ADR 不规定调用顺序。
