# 大扫除按同类扫描，不按票面条目施工

Status: accepted（owner 范围纠正，2026-08-02）

#58 的 F-ID 表、文件名和当前发现只是不完全实例与证据索引，不构成施工白名单。大扫除必须按已裁决的校验类别扫描全仓：凡具有同类拒绝行为的输入、输出、持久化、tool schema、发布 schema、runtime 二次校验、测试和文档，无论名称、位置、是否已列 ID，均在范围内。

施工完成后按同一类别重新扫描残余；任何保留实例都必须落入已批准的特别理由类别。验收判断的是同类行为是否清完，不是既有清单是否逐项打勾。本裁决只规定 #58 的工作范围与验收方法，不新增常驻 scanner、gate 或免疫机制。
