# Owner correction 005: retain value-bearing evidence, not execution exhaust

This correction supersedes amendment 004's requirement that every formal invocation produce a cold forensic stream. The tracked-hot/cold distinction remains available, but cold retention is exceptional rather than automatic.

## Normal proof boundary

For ordinary role work, the decision-bearing record is the sealed authority/task identity, mechanically accepted typed Receipt, package-observed Soul/method-audit acceptance where applicable, review report, finding dispositions, plans/repairs, committed target/range identity, test evidence, and specifically cited exhibits. These are the durable claim chain.

Routine tool calls, stream deltas, repeated file reads, internal reasoning, and event exhaust are not retained merely to re-prove a Receipt already accepted through the package runtime and its applicable audit. Audit acceptance proves only that the package accepted the demonstrated role/method output under its documented audit law. It is not cryptographic authenticity, independent fact verification, or protection against a malicious host fabricating archive bytes.

## Raw-session default and admission

Raw session capture remains private scratch during execution so the Recorder can extract the lawful Receipt and child/audit outcome. By default it is not promoted to hot Git or cold storage and is deleted after successful core promotion or required failure cleanup. The hot manifest records `not retained` and the governing default reason; a digest without bytes is optional diagnostic metadata and must never imply retrievability.

Raw events may be retained only under an explicit caller selection made before irreversible cleanup, using one of these reasons:

1. the event/model-visible lifecycle is itself an owner-approved behavioral recording or regression exhibit;
2. extraction/audit/tool lifecycle is the subject under test or dispute;
3. caller policy requested retention for a child/Recorder failure class before invocation, and that class occurred;
4. an identified forensic exhibit cannot be reconstructed from the Receipt, audit acceptance, Git facts, and ordinary tests.

The caller supplies the admission reason before invocation or as a predeclared outcome-conditioned policy such as failure-only retention. The Recorder mechanically applies that selection after the child outcome; it does not ask a model, wait indefinitely, infer future value, retry, or spawn again. If no valid selection matches, raw scratch is deleted. A later desire to inspect an unretained session is not evidence that the earlier archive was incomplete.

When admitted, raw events are stored outside the hot repository using amendment 004's lossless compressed cold-object contract and durable locator. Only the specifically cited object/range enters the hot claim chain as an exhibit reference. Git-resolvable source and decision artifacts remain references and are never copied into hot payloads.

## Legacy and branch correction

Legacy migration promotes the value-bearing claim chain and only raw sessions meeting the explicit admission reasons. Existing #10 bootstrap sessions were useful once as capacity evidence, but their decision-bearing Receipts/manifests and capacity measurement now carry that fact; ordinary tool/event payloads are not independently valuable historical memory. The final mergeable branch must be reconstructed from the default branch with the canonical claim-chain artifacts and without the 398 MiB raw session blobs. Preserve exact Receipts, authority amendments, reviews, adjudications, manifests corrected for omitted payloads, and explicit migration dispositions. The current oversized remote feature branch is a temporary migration source, not the final archive and not a permanent cold-store promise.

No automatic cold archive, retention daemon, summarizer, model admission role, vector index, Git LFS, object-storage SDK, or GitHub-specific transport is authorized. Less is more: preserve what carries a claim, decision, or irreducible proof; discard reproducible execution exhaust.
