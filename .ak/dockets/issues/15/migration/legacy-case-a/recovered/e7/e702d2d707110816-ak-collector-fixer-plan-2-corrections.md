Mechanically inspect/use the schemas actually registered by the in-process Pi extension, and run every malformed output row separately: unknown leg field, missing/invalid unavailable scope, scope on valid, scope on missing, blank rationale, empty refs, and unknown top-level field. Specify explicit allowed same-leg ref classes and reject wrong-leg/non-qualifying model refs for missing as well as unavailable. Keep full attempts at receipt root, but never place another leg’s comment/snapshots/recovery/diagnostics in a leg or terminal report.

Table each decoy independently, then prove a clean same-leg candidate succeeds and both leg/report refs contain only qualifying same-leg proof.
